Aljé Matcha — POS & storefront

A two-part system for a pop-up matcha business: a local point-of-sale app that keeps working with no signal and syncs orders when it's back online, paired with a public web storefront for menu, pre-orders and pop-up schedules.

  • Local POS built with Expo, tunnel-deployed so it runs on-site without a server
  • Supabase as the shared database; orders queue offline and sync when connected
