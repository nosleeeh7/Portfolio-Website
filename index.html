Offline-first POS Full-stack In production

Aljé Matcha — offline POS + online ordering

A two-part system for a real pop-up matcha business. An iPad POS that works with zero signal and a public storefront where customers order ahead — both sharing one Supabase backend so online orders land in the same queue the staff already use.

  • POS (Expo / React Native): menu, recipes, ingredient-level inventory, sales and daily history stored in local SQLite; a one-tap sync upserts everything to Supabase, uploads menu photos to Storage, and marks sales as synced
  • Storefront (Next.js on Vercel): ordering only opens when the owner's master switch is on and a pop-up is scheduled today in Philippine time; prices and delivery fees are recomputed server-side so the browser is never trusted
  • Delivery pricing from a Leaflet map pin — Haversine distance from the shop, tiered ₱ fee; GCash screenshot verification with an admin dashboard for orders, events and settings
